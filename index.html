Как пользоваться Python Sandbox

Шаг 1: Пишите код в левой панели

• Вводите любой Python код в редакторе слева

• Используйте готовые примеры для быстрого старта

• Код автоматически сохраняется

Шаг 2: Запускайте код

• Нажмите кнопку "Запустить код" или Ctrl+Enter

• Код начнет выполняться построчно

• Результат появится в правой панели

Шаг 3: Работа с input()

• Когда код дойдет до input(), в правой панели появится поле ввода

• Введите нужное значение и нажмите Enter или "Отправить"

• Код продолжит выполнение с введенным значением
