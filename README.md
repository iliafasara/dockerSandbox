# 🐍 Python Sandbox - Онлайн выполнение Python кода

## 📋 Описание проекта
Веб-приложение для безопасного выполнения Python кода в изолированной среде. Проект разработан для дисциплин "Технология разработки ПО" и "Инструментальные средства разработки ПО".

### ✨ Основные возможности
- ✅ Безопасное выполнение Python кода
- ✅ Изоляция через Docker контейнеры
- ✅ Проверка кода на опасные конструкции
- ✅ Подсветка синтаксиса Python
- ✅ Автосохранение кода
- ✅ Готовые примеры для обучения
- ✅ Адаптивный интерфейс

## 🚀 Быстрый старт

### Способ 1: Запуск с Docker (рекомендуется)
```bash
# Клонировать проект
git clone <repository-url>
cd python-sandbox

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
python app.py

# Открыть в браузере
http://localhost:5050
